# File Aggregator - دليل الاستخدام المتكامل

هذا المشروع مصمم لجمع محتويات ملفات برمجية محددة وإنشاء خريطة لهيكل المشروع. يتوفر المشروع الآن بـ 3 واجهات مختلفة لتناسب احتياجاتك:

## 1. الواجهات المتاحة (Available Interfaces)

يمكنك تشغيل الأداة بثلاث طرق مختلفة من التيرمينال:

| الأمر (Alias) | نوع الواجهة | الاستخدام المثالي |
| :--- | :--- | :--- |
| **`agg`** | **CLI** (Direct) | التشغيل السريع والمباشر للقائمة الموجودة في `files.txt`. |
| **`aggt`** | **TUI** (Terminal UI) | التصفح التفاعلي واختيار الملفات داخل التيرمينال (خفيف جداً). |
| **`aggg`** | **GUI** (Window) | واجهة نافذة كلاسيكية (Tkinter) بنظام Dark Mode. |

---

## 2. أوامر التيرمينال السريعة (CLI Commands)

بدلاً من فتح الملفات يدوياً، يمكنك إدارة قائمة الملفات بسرعة:

- **إضافة ملف للقائمة:** `agg-add filename.py`
- **عرض القائمة الحالية:** `agg-list`
- **تفريغ القائمة:** `agg-clear`
- **تشغيل التجميع المباشر:** `agg`

---

## 3. شرح الواجهات التفاعلية (Interactive Interfaces)

### نسخة التيرمينال التفاعلية (`aggt`):
- **المميزات**: شجرة ملفات تفاعلية، مربعات اختيار (Checkboxes)، سجل عمليات مباشر، وخفة متناهية في استهلاك الموارد.
- **الاختصارات داخل الأداة**:
    - `r`: تحديث شجرة الملفات.
    - `a`: بدء عملية التجميع (Aggregate).
    - `c`: مسح قائمة الانتظار.
    - `q`: الخروج.

### نسخة النافذة المستقلة (`aggg`):
- **المميزات**: واجهة رسومية Dark Mode، تدعم السحب والإفلات (اختيار متعدد)، وزر لتغيير مجلد المشروع (`Open Root`).
- **طريقة العمل**: اختر الملفات من الشجرة اليسرى، اضغط `Add Selected` ثم `Run Aggregate`.

---

## 4. المخرجات (Outputs)

بمجرد انتهاء التشغيل (بأي طريقة)، ستجد:
1.  **`arena.txt`**: يحتوي على محتوى جميع الملفات المجمعة مع فواصل واضحة.
2.  **`structure.txt`**: يحتوي على رسم شجري لهيكل المشروع بالكامل.

## 5. التخصيص (Ignore Patterns)
لتجاهل ملفات أو مجلدات معينة، أنشئ ملف `.index_ignore` في جذر المشروع الذي تعمل عليه وأضف داخله الأنماط التي تريد تجاهلها.

---

## نصيحة إضافية (Pro Tip)
لجعل التشغيل أسهل من أي مكان، يمكنك إضافة `alias` جديد في ملف `~/.zshrc`:

```bash
alias agg='python3 /mnt/data/programming/Python/Projects/context/aggregator.py'
alias aggt='/mnt/data/programming/Python/Projects/context/.venv/bin/python3 /mnt/data/programming/Python/Projects/context/aggregator_tui.py'
alias aggg='/mnt/data/programming/Python/Projects/context/.venv/bin/python3 /mnt/data/programming/Python/Projects/context/aggregator_gui.py'
```
بعد إضافة هذه الأسطر وعمل `source ~/.zshrc` بنفس الطريقة التي فعلناها سابقاً، ستتمكن من كتابة `agg` أو `aggt` أو `aggg` في التيرمينال لتشغيل الأداة مباشرة بشرط وجود ملف `files.txt` في المجلد الحالي.
